① 曲目预算

cell=共享时间轴最小格;机器路径必须容纳全部 cell,顺序=时间顺序。折叠只改空间不改音乐。载入 MIDI 会自动填这两个数。

② 走线 / 播放形式

支持 S 波浪 / 直线 / 自定义(走线)/ 原地播放。自定义=拖节点画路线(导出 waypoints)。多轨分布在下方③和弦模式里开启(导出 form=multilane)。
XRUN 小 / ZMAX 大 → X 更短(压缩更高)、Z 更宽。只改形状不改节奏。
拖动节点调位(画布不会误加点);右键删。加点/撤销用按钮。路径 X→Z 直角连,cell 顺序铺=时间不变。
选中节点:无
原地播放=不铺线,只摆调色板音符盒(用到的不同音各一个),数据包按节奏在方块侧面点红石块反复触发。调整主体=方块本身/网格。

③ 和弦模式

v1 支持 合并和弦(辐射) 与 多轨分布(导出 form=multilane;每声部一轨,直线,过 forceload 上限会硬失败→改 S 波浪)。
多轨分布=每条声部单独一轨、共享唯一延迟骨架(绝对同步+列对齐, 旧版24/30)。轨间距防红石串扰。侧视里拖每条轨调相对 Z 位。
合并辐射=一个导体同刻向上+左右辐射 ≤3 音(紧凑, 当前 48/43)。关掉它=改用左边多轨分布。

④ 起点 与 播放方向

脉冲从起点沿所选方向推进。预览按 +X 画形状, 生成器按 start_dir 旋转摆放(+X / -X / +Z / -Z 均支持)。
脉冲从起点沿此方向推进(中继器朝向随之)。预览用起点标记+方向读数表示;生成器按此摆放/朝向机器。

⑤ 线宽 与 空格

线宽/gap 仅多轨分布(multilane) 生效, S波浪/直线/自定义尚未接入(导出恒为默认 3/1)。
线宽=发声列向脊柱两侧伸的音符盒数。gap=相邻折额外留空,防音符列重叠/红石串扰。

⑥ 信号基底方块

仅列能承载红石信号的实心不透明方块(已自动滤掉 玻璃/台阶/楼梯/树叶/荧石 等不导通方块)。当前:minecraft:stone

⑦ 信号轨道(粒子同步)

多轨分布(multilane) 形态消费信号轨, 支持 3D 偏移 dx / dy / dz。完整的关键帧粒子请用 particle_editor.html。
平行跟随主脉冲的中继器链(与音乐完全同步, 无音符盒), 供玩家在旁摆命令方块触发粒子。相对脊柱偏移 (dx, dy, dz)。
信号轨 仅多轨分布(multilane) 消费, 当前形态导出会置空。到③和弦模式切到「多轨分布」再加轨道。
