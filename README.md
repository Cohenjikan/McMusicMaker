# RedstoneMusic — 音符盒音乐"真实重构"调研

把红石音乐从"切片回放原曲"升级为"分轨 → 转写音高 → 真实乐器取样 → 按节奏 playsound"的**可行性调研 + 落地方案**。引擎 Minecraft Java **1.21.8**。

## 文档
- **`00_继承分析.md`** — 既有研究继承:现有探索清单、可复用资产(保留/改造/废弃)、**两条已被证伪的死路**(切片回放 + 早期 MIDI 合成)。
- **`01_可行性与架构.md`** — 主报告:硬约束逐条核实(MC 1.21.8)、**三档可行性对照**(纯原版+RP / 数据包+RP / Mod)、推荐架构、工具链选型(分轨/转写/样本库许可)、**最小 POC 计划**。

## 一句话结论
推荐 **Tier 2(数据包 + 资源包)**:**复用现有 v7 红石时序引擎,只把声音源从"原曲切片"换成"真实乐器样本 + 按音高 pitch"**。三堵硬墙(无 note-off / 247 同时发声上限+卡顿 / pitch 仅 ±1 八度)决定设计取舍。POC = **晴天吉他轨(已缓存)→ basic-pitch → Karoryfer CC0 电吉他样本 → v7 时序**。
